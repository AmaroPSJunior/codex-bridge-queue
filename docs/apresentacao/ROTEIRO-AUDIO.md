# Roteiro de áudio — explicação do projeto

Idioma: português do Brasil. Duração estimada: 45–60 segundos, em ritmo de aproximadamente 150–190 palavras por minuto. Faça um ensaio antes de gravar; a duração depende da voz e das pausas.

## Texto para narrar

Imagine pedir uma tarefa ao ChatGPT e ter o seu celular ajudando a realizá-la. É isso que esta ponte organiza. Você faz o pedido, e ele entra em uma fila segura, como uma encomenda com número e título. O GitHub ou o Supabase cuidam dessa organização e do transporte. No celular, o Termux recebe a tarefa e a entrega ao Codex, que executa o trabalho conforme as permissões disponíveis. Depois, o resultado volta para o mesmo lugar, pronto para ser consultado e apresentado pelo ChatGPT. Você acompanha algo simples, como Tarefa 1 — Verificar a ponte, sem precisar lidar com códigos complicados. A meta é que a resposta retorne automaticamente ao ChatGPT. Hoje, isso depende da consulta pela integração: não estamos afirmando que uma notificação espontânea já funciona. Assim, cada etapa fica mais fácil de acompanhar, com cuidado para não repetir pedidos nem expor informações privadas.

## Orientações para gravação

Use voz clara e acolhedora, com pausas curtas entre as etapas. Leia “Tarefa um — Verificar a ponte”. Não narre chaves, endereços privados ou exemplos reais de usuários. Salve a gravação final como `explicacao-projeto.mp3` nesta pasta. A gravação ainda precisa ser produzida; este roteiro não é um arquivo de áudio.
